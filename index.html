METHODOLOGY

数据来源与更新规则

这里的“自动更新”意味着什么？

已实现：国别页面通过世界银行公开 API 获取最新已发布的统计数据（例如人口、GDP、通胀、制造业占比）。网络不可用时优先读取站点快照；尚无数据时明确标记“未取得”，绝不代填零值。

已编写UN Comtrade 双边贸易采集脚本并由定时任务调用；有可用官方返回值后在第03模块显示进出口、贸易差额和趋势。贸易采用中国作为唯一报告国，不能与非洲伙伴国自行发布的镜像统计直接混为一谈。

投资、贷款、工程、民调、军事等来源已经建立统一JSON数据库文件与手工核验导入程序，但其中多数专题数值仍未入库。部分国家的项目和政策事件已有来自官方、企业及通讯社的可点击来源记录。所有未取得数据都将显示未入库，而非零。

重要区分

网页的访问日期 ≠ 原始数据统计年份；投资流量 ≠ 投资存量；工程承包 ≠ 对外直接投资；贷款承诺 ≠ 债务余额；总体公众评价 ≠ 青年群体态度。

更新与个人研究

GitHub Actions 已配置每周检查世界银行与UN Comtrade公开数据，成功后更新静态数据快照；UN Comtrade存在接口配额和缺失年份限制，失败会保留历史数据。其他来源按照数据发布情况导入。网站上的个人研究笔记只保存在当前浏览器的 localStorage，并未同步至远程账户。部署为公开网页不意味着具备用户登录或私人云备份。
